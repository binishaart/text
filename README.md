Text-to-3D Model Generator

A Flask-based web app that generates simple 3D models (GLB/OBJ) from natural language prompts. Enter a description like "sphere", "cube", or "cone" and get a downloadable 3D model instantly. Lightweight UI with colors, deployable via GitHub and Render.

Features

Generate 3D models (GLB/OBJ) from text prompts

Simple keyword-based procedural generation

Downloadable models

Colorful and responsive web UI

Compatible with Python 3.14, Flask, and Gunicorn
